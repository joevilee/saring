# SARING

Track the trend, not the noise.

A simple personal body composition tracker for monitoring:

- Weight
- Body Fat %
- Skeletal Muscle

SARING uses trend data to help filter out daily measurement noise and make longer-term changes easier to see.

## Features

- Weight, body fat, and skeletal muscle tracking
- Trend calculation
- Goal progress
- Planned weight-loss rate
- Estimated calorie balance
- CSV import/export
- Data stored locally in the browser

## Privacy

No account or cloud sync is required. Your tracking data is stored locally in your browser.
